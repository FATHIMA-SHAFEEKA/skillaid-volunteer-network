# SkillAid — Smart Emergency Volunteer Network

BSc Final Year Project — A full-stack web platform for 
coordinating emergency volunteers across Sri Lanka.

## Features
- GPS map with live incident visualization (Leaflet.js)
- Real-time volunteer filtering by skill, location & availability
- Multi-role authentication (Volunteer / Reporter / Admin)
- District-zone proximity algorithm
- Complete SRS documentation and UML diagrams

## Tech Stack
PHP · MySQL · JavaScript · Leaflet.js · Bootstrap · HTML5 · CSS3

## Testing
All 10 functional, usability and UAT test cases passed

BSc Final Year Project — Solo architected and developed
